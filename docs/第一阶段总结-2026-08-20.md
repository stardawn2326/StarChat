# 第一阶段总结（外部 Live2D 方向修订，2026-08-21）

## 已完成

- Electron + React + TypeScript 工程可构建，窗口使用无边框、透明、置顶的桌宠基础结构。
- 设置界面支持 API 地址、模型、温度、最大 Token、追加系统提示词、置顶开关和外部模型入口。
- `settings.json` 与 `secrets.json` 分离保存；渲染层只看到 API Key 是否存在，不接收密钥内容。
- `code/src/roles/baoyin.role.json` 提供白音默认人格包，`modelAsset` 保持为空，避免把人格绑定到白音专属模型。
- 外部 `.model3.json`/目录只读检查已覆盖 `.moc3`、纹理、physics3、CDI3、exp3、motion3、同目录额外资源和编辑器文件诊断。
- CDI3 参数绑定、exp3/motion3 语义路由、参数范围裁剪、未知语义回退和模型级适配数据已实现。
- 外部模型切换前有许可确认；源目录不写入，外部模型不进入打包文件清单。

## 验证证据

- TypeScript 类型检查：通过。
- Vitest：外部模型导入/参数映射/安全回退测试与 API 流式测试通过。
- `electron-vite build`：主进程、preload 和 renderer 均生成到 `code/out/`。
- `electron-builder --win portable`：生成项目内 Windows portable EXE。

## 当前边界

桌宠当前仍使用 CSS 安全占位层；已登记的外部模型会显示检查结果和适配状态，但尚未接入具体 Cubism runtime。不要把“只读导入通过”解释为“模型已渲染或 Live2D 已完成”。

## 旧 B1 文件

旧的白音 B1 分层/PSD/Cubism 规范、制作计划和日志保留为历史审计资料，不再是当前实施计划，不要求制作或等待白音专属模型。

## 后续建议

优先接入一个用户已授权的外部 Cubism runtime 适配器，复用 `Live2DAdapterConfig` 进行实例化、参数写入和语义事件播放；随后用至少两个结构不同的外部模型验证资源缺失和映射回退。
