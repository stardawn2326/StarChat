# 白音角色视觉基准

## 固定识别特征

- 成年女性角色，外观年龄 18 岁。
- 长白发、紫色瞳孔、柔和脸型。
- 较小但匀称的成年人体型。
- 主色为月白、淡紫与深灰。
- 默认服装和配饰只描述白音人格的视觉参考，不要求制作对应的 Live2D 模型。

## 性格表演方向

- 外在表现偏傲娇和嘴硬。
- 内在表现耐心、关心用户。
- 天然呆表情应表现为短暂空白和困惑，避免夸张失智化。
- 关系发展后逐渐增加温柔表情与主动互动，但保留独立意见和拒绝能力。

## 外部模型绑定原则

- `assets/character/白音-统一设定稿-v1.png` 仅作为视觉参考，不能直接视为可绑定分层稿。
- 白音人格不得依赖某个 PSD、Cubism 工程、`.model3.json` 或固定参数 ID。
- 程序优先兼容用户选择的合法外部 `.model3.json` 或模型目录，并保持外部资源只读。
- 表情、动作和参数使用语义名称映射；模型差异由模型级适配器处理，缺失资源安全回退。
- 外部模型的服装、发型、比例可以与白音视觉参考不同，不改变人格、称呼和关系状态。

## 默认语义集合

表情：

- neutral：自然待机
- caring_smile：关心和温柔微笑
- bright_smile：明亮笑容
- annoyed：不满
- embarrassed：尴尬躲闪
- tsundere_pout：傲娇鼓脸
- worried：担忧
- anxious：不安
- blush：害羞
- surprised：惊讶
- confused_blank：天然呆与短暂困惑
- sleepy：困倦

动作：

- idle：呼吸与轻微身体摆动
- greet：被唤醒后看向用户并问候
- look_away：嘴硬或害羞时移开视线
- lean_forward：认真倾听或关心用户
- nod：同意
- shake_head：拒绝
- thinking：认真思考
- stretch：伸展

这些语义名称是人格/表演层契约，不是某个 Cubism 文件名或某个白音模型的绑定清单。
