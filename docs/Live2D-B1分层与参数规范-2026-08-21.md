# 白音 B1 Live2D 分层与参数规范

- 日期：2026-08-21
- 版本：B1-0.2（正式分层原画制作阶段）
- 绑定目标：桌宠优先的上半身正式模型；保留全身服装和鞋的扩展位

## 正式原画画布规格

- 画布：`4096 × 6144 px`，RGB，8-bit，透明背景，建议 300 ppi 元数据。
- 构图：自然正面站姿；头部基本正视，肩部放松，双臂与躯干略有间隔，双手和鞋底完整可见；呆毛、鞋底和长侧摆均不得裁切。
- 安全区：角色主轮廓距画布边缘至少 160 px；长发、裙摆、链饰和晶体的运动余量另留 160–320 px。
- 纹理预算：以桌宠上半身显示为主，正式 PSD 保留 4096 级绘制精度；后续 Cubism 纹理打包时按部件拆为 2048/4096 纹理页，禁止因纹理页限制合并左右眼、手、腿、主要发束或可开关装饰。
- 版本策略：正式源文件目标路径为 `assets/live2d/baoyin-b1/source/baoyin-b1-front-v001.psd`；在实际绘制并保存前不得创建同名伪分层文件。当前已有的 `qa/baoyin-b1-reference-review-v001.psd` 仍仅为单层参考快照。

该规格是制作基线，不代表正式 PSD 已完成；在 Photoshop 中实际创建后须复核画布属性和边界截图。

## 分层原则

- 每个会发生相对位移、缩放、变形或显隐切换的对象都要有独立层组。
- 眼睛、眉、嘴和装饰不能合并到脸或服装底图。
- 前发、侧发、后发、外侧长发和发饰分开；长发的遮挡补绘必须位于正确的底层。
- 肩披、袖子、裙片、长侧摆、链饰、宝石和玫瑰均可独立开关或单独挂物理。
- `GUIDE_*` 只用于制作，不进入纹理和 runtime。
- 正式绘制必须以独立对象重绘为主，参考板只作为锁定的低不透明度导引；不得用矩形自动分割、粗蒙版、简单抠图或背景擦除结果冒充可动层。
- 所有被发、肩披、袖子、马甲、裙片、袜口或装饰遮挡的区域都要在对应下层中补全，补绘边缘须在 100% 和 200% 检查。
- 以下是生产命名契约，不代表当前已经存在这些图层文件。

## 可见性开关

| 开关 | 对象 | 默认 | 说明 |
| --- | --- | --- | --- |
| `Outfit_B1` | 全套 B1 服装 | on | 正式主服装，不与早期服装设定混用 |
| `Cape` | 肩披、蕾丝和肩披链饰 | on | 可单独隐藏用于遮挡 QA |
| `LongSideSkirt` | 淡紫长侧摆及玫瑰刺绣 | on | 与裙体和物理链分开 |
| `HairOrnaments` | 发结、玫瑰、晶石、链饰 | on | 装饰组可独立关闭 |
| `Gemstones` | 紫晶/吊坠/水滴晶石 | on | 物理回弹和光泽检查对象 |
| `SilverVines` | 银色藤饰与链 | on | 不得烘焙进马甲或披肩底图 |
| `Guide` | 所有参考图/对齐线 | off | 永不导出 |

## 标准参数

### 头部、身体和视线

| 参数 | 范围 | 用途 |
| --- | --- | --- |
| `ParamAngleX` | -30…30 | 头部左右转；脸、眼、鼻、前发、肩披分级变形 |
| `ParamAngleY` | -30…30 | 抬头/低头；下巴、眼睑、刘海和衣领联动 |
| `ParamAngleZ` | -20…20 | 头部侧倾；耳、发束、肩线跟随 |
| `ParamBodyAngleX` | -10…10 | 上半身左右倾斜 |
| `ParamBodyAngleY` | -10…10 | 上半身前后倾；桌宠优先小幅 |
| `ParamBodyAngleZ` | -10…10 | 肩线和躯干侧倾 |
| `ParamEyeBallX` | -1…1 | 双眼水平视线，允许独立微调 |
| `ParamEyeBallY` | -1…1 | 双眼垂直视线 |
| `ParamBreath` | 0…1 | 胸口、肩披、长发和袖口的轻微呼吸 |

### 眼、眉、口

| 参数 | 范围 | 用途 |
| --- | --- | --- |
| `ParamEyeLOpen` / `ParamEyeROpen` | 0…1 | 左右眼独立睁闭、眨眼和表情覆盖 |
| `ParamEyeLSmile` / `ParamEyeRSmile` | 0…1 | 微笑眼/弯月眼，可选扩展 |
| `ParamBrowL` / `ParamBrowR` | -1…1 | 眉毛抬起、压低、内收 |
| `ParamMouthForm` | -1…1 | 嘴角下压/自然/上扬 |
| `ParamMouthOpenY` | 0…1 | 口腔开合，驱动 A/I/U/E/O 的切换基础 |
| `ParamMouthA` / `ParamMouthI` / `ParamMouthU` / `ParamMouthE` / `ParamMouthO` | 0…1 | 五元音形态，作为语音或文本表演适配层的输入 |
| `ParamBlush` | 0…1 | 腮红透明度和范围 |

### 表情覆盖

表情文件只改变参数和可见性，不把人格逻辑写进 Cubism 文件名。默认优先使用 `ParamEye*`、`ParamBrow*`、`ParamMouthForm`、`ParamMouthOpenY`、`ParamBlush` 的连续值；牙齿、舌头、泪滴和汗滴作为语义表达的可见性层。

## Deformer 与物理建议

- `D_Body`：身体总层，承接 `ParamBodyAngleX/Y/Z` 与 `ParamBreath`。
- `D_Head`：头部总层，承接 `ParamAngleX/Y/Z`。
- `D_Face`：脸、耳、鼻、腮红；避免让耳朵穿出头发。
- `D_Eye_L/R`：眼白、虹膜、睫毛、眼睑和高光成对绑定。
- `D_Mouth`：嘴唇、口腔、牙齿、舌；极限开口时检查下巴和领口。
- `D_HairFront_L/R`、`D_HairSide_L/R`、`D_HairBack`：分别处理转头时的遮挡与延迟。
- `D_Cape_L/R`、`D_Sleeve_L/R`、`D_Skirt_L/R`：肩披、灯笼袖、裙片轻微跟随身体。
- 物理组建议：`Physics_Hair`、`Physics_Cape`、`Physics_Sleeve`、`Physics_SkirtTail`、`Physics_Gem`、`Physics_Chain`。
- 每组先以小幅阻尼回弹为目标，先验证不破面，再提高摆幅；链饰和宝石不得穿过脸、手或裙边。
