# B1 Live2D 视觉 QA 清单

状态：等待 PSD/Cubism runtime；未通过项目视为未完成。

## 基础加载

- [ ] `.cmo3` 可打开，图层树与 `layer-manifest.json` 对齐。
- [ ] `.model3.json` 可被 Viewer/宿主加载，无纹理路径错误。
- [ ] 纹理边缘无参考板背景、白色矩形或版式装饰。
- [ ] `GUIDE_REFERENCE_LOCKED` 不进入 runtime。

## 参数

- [ ] `ParamAngleX` 左右极限：脸、眼、鼻、前发、后发和肩披不破面。
- [ ] `ParamAngleY` 上下极限：下巴、嘴、领口、刘海无断层。
- [ ] `ParamAngleZ` 侧倾：耳、发束、饰品跟随自然。
- [ ] `ParamBodyAngleX/Y/Z` 小幅运动不会让袖口、手、披肩脱离。
- [ ] `ParamEyeLOpen/ROpen` 可独立眨眼，睫毛和眼白不穿插。
- [ ] `ParamEyeBallX/Y` 视线极限不跑出眼眶。
- [ ] `ParamMouthForm` 与 `ParamMouthOpenY` 极限不露出未补绘区域。
- [ ] A/I/U/E/O、牙齿、口腔、舌头切换无重影。
- [ ] `ParamBreath` 只产生轻微呼吸，不移动锚点饰品。

## 物理

- [ ] 发丝有延迟和阻尼，回弹后不穿过眼睛、肩披和手。
- [ ] 袖子和披肩运动时蕾丝边缘完整，无背景污染。
- [ ] 不对称长侧摆的物理方向正确，水晶链饰不穿裙片。
- [ ] 宝石与银链有固定锚点，回弹后回到稳定位置。

## 表情/动作

- [ ] 12 个表情均可由语义 ID 触发，切换时无残留状态。
- [ ] 8 个动作至少完成上半身可实现范围；全身姿态标记为扩展项时不影响待机。
- [ ] `neutral`、`caring_smile`、`worried`、`annoyed` 与现有桌宠语义事件兼容。
- [ ] 表情与动作叠加时，动作不覆盖眼口关键表情。
